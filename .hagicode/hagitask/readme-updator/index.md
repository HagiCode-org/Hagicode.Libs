# README requirements

## Audience and focus

- Address .NET developers who use the `HagiCode.Libs.*` NuGet packages for CLI provider integrations, prompts, skills, imaging and repository exploration.
- Open with the workspace description, the license and package badges, and the project list.

## Required content

- Keep the projects list, getting started, NuGet publishing, provider usage, shared pooling, cross-platform validation and design goals as the current README does.
- Link to `docs/` guides for detail on AVIF, Git backend, skills API and CLI discovery instead of copying them.

## Exclusions

- Exclude NuGet API keys, tokens, secret values, internal hosts, machine-specific paths and private links.
- Do not claim support for a provider or platform that `src/` and `tests/` do not show.
