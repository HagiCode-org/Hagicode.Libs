# Vendored CodexSharpSDK

This directory contains vendored source derived from the upstream `ManagedCode.CodexSharpSDK` project.

- Upstream repository: `https://github.com/managedcode/CodexSharpSDK`
- Upstream NuGet package: `https://www.nuget.org/packages/ManagedCode.CodexSharpSDK`

The original upstream MIT license is preserved verbatim in `LICENSE.ManagedCode.CodexSharpSDK.txt`.

When `HagiCode.Libs.Providers` is packed, both files are included under `vendor/codex/` in the resulting NuGet package.
